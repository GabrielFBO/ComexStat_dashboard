# Brazil ComexStat Dashboard

Brazil ComexStat Dashboard is a data visualization project focused on Brazilian import and export operations between 2022 and May 2026.

The project was developed to explore data analysis, SQL queries, JavaScript programming, and interactive dashboards using official Brazilian foreign trade data.

## Features

* Monthly import and export analysis
* Comparison between multiple years
* Country-to-country comparison
* Top N trading partners ranking
* Interactive filters
* Key Performance Indicators (KPIs)

  * Total USD Value
  * Number of Records
  * Top Trading Partner
* Responsive interface for desktop and mobile devices

## Technologies Used

### Backend & Data Processing

* Python
* Pandas
* SQL Server

### Frontend

* HTML5
* CSS3
* JavaScript (ES6)

### Data Visualization

* Chart.js

## Data Source

The data used in this project was obtained from the Brazilian foreign trade statistics platform (ComexStat), maintained by the Brazilian government.

## Main Analyses

### Monthly Analysis

Compare import and export values by month across multiple years.

### Country Analysis

Compare trade performance between selected countries.

### Ranking Analysis

Display Top N countries based on total trade value for selected years.

### KPI Dashboard

Quick overview of trade performance indicators.
